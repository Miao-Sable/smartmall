# 智慧购物 H5

> 扫码即分析，让商品适不适合你一眼可见。

一款辅助购物的 H5 应用。用户扫描商品条形码或二维码后，应用获取商品信息，并结合个人过敏源、饮食偏好与消费历史，给出过敏提醒、成分分析、匹配度评分、价格趋势和个人消费仪表板。

**目标版本**：v0.2（MVP 核心闭环）  
**技术栈**：Vue3 + Vant + FastAPI + SQLite/PostgreSQL

---

## 项目定位

智慧购物 H5 不是要做大而全的电商应用，而是用 MVP 思维跑通一条完整、可演示、可部署、可扩展的购物辅助链路：

**注册登录 → 设置档案 → 扫码 → 商品分析 → 扫描历史 → 首页仪表板**

在核心闭环稳定后，再逐步加入差异化能力，把普通扫码工具升级为 **过敏 / 健康购物决策助手**。

### 差异化创新

围绕一句话做创新：

> **扫一下，不只告诉你能不能买，还告诉你为什么、风险多大、可以买什么替代。**

优先实现：

1. **安全替代推荐引擎**  
   扫描到高风险商品后，推荐同品类、无用户过敏原、价格相近的安全替代品。

2. **可解释匹配度评分 + 红黄绿交通灯**  
   红 = 不建议，黄 = 谨慎，绿 = 适合。  
   展示加减分原因，例如：“含牛奶 -40；高糖 -10；价格低于均价 +5”。

3. **购物清单预检**  
   用户输入购物清单，提前预检哪些商品含过敏源，并生成安全替代清单。

4. **家庭多档案 / 场景模式**  
   支持儿童、老人、孕妇、控糖、减脂、健身等档案，扫描时切换“给谁买”。

5. **健康周报与购买时机建议**  
   展示“本周扫描 23 件，避开 5 次过敏风险，高糖商品占比下降 12%”等洞察。

后续可扩展：OCR 配料表识别、离线安全模式、语音播报、成分白话翻译、交叉过敏知识图谱、结构化避坑评价、众包纠错等。

- pnpm / npm / yarn

## 业务规则

### 过敏提醒规则

- 用户档案中的过敏源与商品成分表做关键词匹配。
- 命中过敏源：高危提醒 + 成分高亮。
- 未命中：显示“未发现已知过敏源”，并展示免责声明。

### 匹配度评分规则（0-100 分）

- 基础 100 分。
- 命中过敏源：扣 50 分，标记“不推荐”。
- 不符合饮食偏好：每项扣 10 分。
- 最终等级：
  - 90-100：非常适合
  - 70-89：比较适合
  - 50-69：一般
  - 0-49：不适合

### 扫描历史规则

- 每次成功扫码或手动输入后保存记录。
- 记录包含：商品名、条码、时间、过敏风险、匹配度。
- 重复扫描按时间倒序保存，不覆盖。

### 商品数据规则

- MVP 使用本地 mock JSON。
- 预留第三方 API 接口位置。
- 查不到商品时提示“暂无数据”，引导手动输入。

### 权限与隐私

- 未登录：可看首页，不可扫码和保存历史。
- 已登录：可扫码、设置档案、查看历史。
- 过敏源和饮食偏好加密存储，不公开。

## 边界限制

### 功能边界

- 不做支付、下单、电商跳转。
- 不做医疗诊断。
- 不做复杂社交系统。
- 不做实时比价。
- 不做 AI 图像识别。
- 不保证覆盖所有商品。

### 技术边界

- H5 扫码优先支持微信内置浏览器、Safari、Chrome。
- 第三方商品 API 先不接，先用 mock。
- 短信验证码先不接真实服务。
- 历史价格先模拟。

## 合规与免责声明

> 本应用提供的过敏提醒和成分分析仅供参考，不构成医疗建议。请以商品包装说明和医生意见为准。

- 过敏源和饮食偏好加密存储，不公开。
